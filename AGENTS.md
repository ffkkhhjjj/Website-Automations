# Local Growth Engine — platform repository

## Code conventions
- TypeScript, strict mode. Node >= 20. ESM (`"type": "module"`); imports in TS
  source files use `.js` extensions for runtime ESM resolution under tsx/node.
- Any schema change: edit `src/db/schema.ts`, run `npm run db:generate`,
  commit both the migration (in `drizzle/`) and the schema change together.
- Migration files in `drizzle/` are generated by drizzle-kit. Never hand-edit
  an applied migration; add a new one.
- All DB access goes through `src/db/client.ts` — do not create ad-hoc pools.
- Business rules belong in `system_settings`, weights in `scoring_versions`,
  and state transitions in `audit_logs` + `lead_state_history`. Nothing
  business-rule-shaped is hard-coded.
- Money is integer cents. No raw payment/card data anywhere.
- External integrations are interfaces marked `requires-configuration` until
  live credentials exist. No fake integrations.

## Team workflow
- All write work on feature branches (one per delegation/brief), never directly
  on `main`. Push the branch and open a PR when the brief's work is complete;
  the team lead merges (never self-merge). Finish by checking out the default
  branch with a clean tree.
- See `/home/team/shared/WORKFLOW.md` for the full team process.
